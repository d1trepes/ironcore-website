# IRONCORE — website & identity

**Главный рабочий репозиторий** нового сайта IronCore. Этот репозиторий содержит исходное ТЗ, актуальные дизайн-решения и в дальнейшем демо-код для передачи WordPress-разработчику. Предыдущие `ironcore-landing` и `ironcore-hero` — только архивные референсы, их не менять без отдельного поручения.

## С чего начать новому чату
1. `docs/PROJECT_STATE.md` — актуальное состояние и очередной шаг.
2. `docs/brief.md` — задача, ограничения, обратная связь клиента.
3. `docs/content.md` — **полный текст ТЗ** с 11 разделами и цифрами.
4. `docs/tz-checklist.md` — контроль полного охвата ТЗ.
5. `docs/visual-direction.md` — как соединить понравившиеся клиенту решения.
6. `docs/design-system.md`, `docs/page-blueprint.md` — правила и компоновка.
7. `CLAUDE.md` — инструкция разработчику (создаётся для этапа реализации).

## Статус
Подготовка документации и дизайн-брифа. **Ни логотипы, ни финальная дизайн-система, ни макеты ещё не согласованы.** Прежде чем реализовывать, выполнить короткий шаг арт-дирекшна и утвердить логотип/герой.

## Границы
- Демо — не production-WordPress и не действующая CRM-интеграция.
- Для WordPress-разработчика нужен handoff с исходниками, ассетами, состояниями элементов, адаптивом и списком интеграций.
- Не придумывать кейсы, отзывы, сертификаты и инженерные гарантии.
- Чаты короткие, решения сохраняются в GitHub; обновлять `docs/PROJECT_STATE.md`.

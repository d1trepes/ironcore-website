# IRONCORE — website & identity

**Главный рабочий репозиторий** коммерческого демо-сайта IronCore. Здесь находятся оригинальное ТЗ, согласованная основа UX-структуры, SVG-логотипы, инструкции для Claude и будущий код. Архивные ironcore-landing и ironcore-hero не изменять.

## Быстрый старт (Claude)
1. Создай Claude Project «IRONCORE — Website» и вставь [инструкции проекта](docs/claude-project-instructions.md) в Project Instructions.
2. Работай с этим GitHub через Claude Code или другой реально подключённый исполнитель кода с правами на запись.
3. Начни с [промпта для первого desktop-чата](docs/claude-chat-prompts.md). Не запускай сразу остальные.
4. Двигайся по [маршруту пяти чатов](docs/claude-workflow.md): desktop → desktop-правки → mobile → QA → презентация.
5. После каждого этапа обновляй [состояние проекта](docs/PROJECT_STATE.md) и сохраняй реальный код, но не объявляй дизайн утверждённым без прямого одобрения пользователя.

## Ограничения
- Демо — не production-WordPress, не активная CRM/Telegram-форма, не подтверждённые PDF.
- Не придумывать кейсы, отзывы, цифры, клиентов, сертификаты и гарантии.
- Будущий WordPress-разработчик должен получить исходники, ассеты, интерактивные состояния, адаптив, инструкцию и список необходимых интеграций.

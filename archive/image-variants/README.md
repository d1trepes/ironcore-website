# Архив: варианты изображений (не подключён к сайту)

Сайт эту папку не использует: index.html и тема WordPress ссылаются только на `assets/images/`.
Здесь хранится всё, что было в демо-подборе картинок (13–17.11.2026), на случай, если заказчик захочет поменять изображения.

## Что здесь
- `variants/<место>/a*.webp` — прежние тёмные картинки (серия «сумерки») для мест, где теперь стоит B.
- `variants/<место>/b*.webp`, `c*.webp` — новые варианты B и C, по 3 размера (полный, -1024w, -640w).
- `picker.js`, `variants.js` — панель «Подбор изображений» (демо).
- `tools/` — slots.py (места, промпты, раскладка выносок первого экрана), build.py, add.py.
- `image-prompts*.md` — промпты для генерации.

## Что выбрано на сайте (17.11.2026)
Принцип: светлые разделы — светлые фото (B), тёмные разделы — тёмные (A), внутри блока одна серия.
- B: первый экран (hero), «Решения» — 3 масштаба и 4 формата, полоса «Начинаем с требований» (`assets/images/band/`).
- A: «Безопасность», «Услуги», «Инженерия», «Материалы».
Выбранные B лежат в `assets/images/` под прежними именами файлов (hero-overview, scale-*, format-*), поэтому пути в шаблонах не менялись.

## Как вернуть другой вариант
1. Скопировать `variants/<место>/<буква>.webp`, `-1024w.webp`, `-640w.webp` в `assets/images/...` под имя нужного файла.
2. Проверить width/height и ширину в srcset у `<img>` в index.html и в шаблоне WordPress (`wordpress/ironcore/template-parts/sections/`).
3. Для первого экрана другой вариант требует другой раскладки выносок: координаты — в `tools/slots.py` (поле `layout`).
4. Пересобрать тему: `bash wordpress/build-theme.sh`.

Скрипты `tools/*.py` писались для папки `demo/`; чтобы запускать их отсюда, поправить пути в `build.py` (ROOT/demo → ROOT/archive/image-variants).

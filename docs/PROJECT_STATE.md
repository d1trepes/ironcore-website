## Следующая команда
1. Пользователь вручную создаёт Claude Project «IRONCORE — Website», вставляет docs/claude-project-instructions.md в Project Instructions и настраивает реальный доступ исполнителя к репозиторию.
2. Начинает новый чат с готовым заданием «Чат 01 — Desktop» из docs/claude-chat-prompts.md.
3. Claude читает README.md, этот статус и CLAUDE.md, затем исходное ТЗ/blueprint, реализует и показывает desktop.
4. После визуального ревью пользователь даёт конкретные правки во втором чате. Без явного утверждения desktop нельзя переходить к полной мобильной версии.

- 11 разделов и все цифры по content.md; не изобретать клиентов/кейсы/гарантии.
- Не повторять AI-шаблоны; геройский рендер без чрезмерной подземной анимации.
- Все неякорные CTA открывают одну демо-форму; #contact содержит открытую форму. Без ложных отправок/скачиваний.
- Ключевые изменения сначала демонстрируются пользователю; утверждённое сохраняется в GitHub. Не заявлять успех сохранения/тестирования без подтверждения.

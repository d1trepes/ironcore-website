# IRONCORE — ассеты и способы подготовки

## Что сейчас есть
- `docs/content.md` — полный текст ТЗ.
- `docs/archive/` — старые правила бренда, прежний hero-бриф и промпты изображений.
- `docs/visual-direction.md` — описания двух присланных в чат свежих концепций.
- В `d1trepes/ironcore-landing` имеются прежние картинки, рендеры, SVG и скриншоты ТЗ. Их не считать автоматически утверждёнными для нового сайта.
- **Новые SVG утверждены дизайнером и добавлены:** основной логотип и знак (включая тёмную и монохромную версии) в `assets/logos/current/`; резервные — в `assets/logos/concepts/`. См. `docs/brand-identity.md`. Новые рендеры сайта ещё не утверждены.

## План организации (создавать по мере появления файлов)
```
assets/
  logos/
    concepts/     # ironcore-alternative*.svg (резервный)
    current/      # ironcore-logo*.svg, ironcore-symbol*.svg (основной)
  images/
    hero/         # hero-overview.webp; hero-cutaway.webp (если согласовано)
    security/     # security-01..06.webp или авторские схемы SVG
    concepts/     # compact, medium, campus, formats...
    services/     # только нужные изображение/схемы
```
Не создавать пустую россыпь файлов «на всякий случай».

## Бриф изображений для нового hero
Качественный архитектурный рендер уровня проекта инженерного бюро: ночной или сумеречный дата-центр на поверхности, строгая современная архитектура, разумные масштабы, рядом компактные контейнерные модули; видимый геологический разрез с конструктивно правдоподобным заглублённым серверным залом, инженерные коммуникации. Сдержанная тёмно-синяя цветокоррекция, подсветка преимущественно естественная/техническая, не sci-fi. Композиция имеет пространство для русского H1, текста и CTA. Без логотипов, текста, водяных знаков, фантастических пропорций. **Не генерировать автоматически до утверждения композиции.**

### Чего не хватает / желательно
- Hero в большем разрешении (≥2560 px по ширине): текущий 1672 px заметно мягче на Retina-экранах 1440.
- Отдельный кадр hero для mobile (вертикальный 4:5) — к этапу 03.
- Реальные PDF для раздела 08 (пример концепции, состав материалов, чек-лист).
- Шрифт: Onest (SIL OFL 1.1) self-hosted в `assets/fonts/`, лицензия рядом.

## Важно для Claude

- SVG-логотипы сохранять как реальные SVG-файлы, не скриншоты.
- При необходимости референсы и сгенерированные кадры загружать по одному после утверждения; изображения должны нести смысл блока.
- Для презентации не использовать изображения с watermark из примеров в исходном ТЗ.
- В WordPress-разработку передать оригиналы, оптимизированные версии и карту путей.

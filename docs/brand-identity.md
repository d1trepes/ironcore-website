# IRONCORE — выбранные логотипы (этап 01)

**Дата решения:** 2026-11-10  
**Статус:** утверждено дизайнером для текущего демо и следующего этапа; отдельное окончательное согласование заказчиком ещё не зафиксировано.

## Основной логотип — «Защищённое ядро» (вариант 01)

Форма: геометрическая многочастная оболочка вокруг красного изометрического куба («ядра») и слово `IRONCORE` справа. Синий нижний элемент продолжает историческую палитру бренда. В написании выделена красным **вторая O** в CORE; первая O остаётся графитовой. **Использовать как основной знак в дизайне сайта**, без самовольной замены.

- Цветная версия для светлого фона: `assets/logos/current/ironcore-logo.svg`
- Цветная версия для тёмного фона: `assets/logos/current/ironcore-logo-on-dark.svg`
- Монохромная версия: `assets/logos/current/ironcore-logo-mono.svg`
- Отдельный знак: `assets/logos/current/ironcore-symbol.svg`
- Отдельный знак на тёмном: `assets/logos/current/ironcore-symbol-on-dark.svg`

## Резервный логотип — «Угловатый модуль» (вариант 02)

Форма: строгая угловатая конструкция/модуль с красной внутренней плоскостью, справа полностью графитовая надпись `IRONCORE`. Утверждён как **рабочая альтернатива**, но **не подменяет основной автоматически**.

- Цветная версия для светлого фона: `assets/logos/concepts/ironcore-alternative.svg`
- Версия для тёмного фона: `assets/logos/concepts/ironcore-alternative-on-dark.svg`
- Монохром: `assets/logos/concepts/ironcore-alternative-mono.svg`
- Отдельный знак: `assets/logos/concepts/ironcore-alternative-symbol.svg`
- Отдельный знак на тёмном: `assets/logos/concepts/ironcore-alternative-symbol-on-dark.svg`

## Формат и правила

Все 10 файлов — настоящие векторные SVG с геометрическими контурами; нет встроенных PNG, фильтров, подключаемых шрифтов, внешних зависимостей. Формы перенесены из согласованных визуальных эскизов, а не заявлены как строго идентичная автоматическая обводка каждого пикселя.

Рабочие цвета в файлах: графит `#17222E`, светлый `#F5F7FB`, красный `#E60028`, синий `#0757C8`; у граней куба дополнительные оттенки красного. **Палитра всей страницы ещё не утверждена** — не подменять решением по логотипам полноценную дизайн-систему.

На тёмном фоне обязательно брать `*-on-dark.svg`: графитовые элементы в нём становятся светлыми, цветные остаются цветными. Не добавлять тени, свечения, 3D-эффекты. Не использовать резервную версию без явного решения.

Перед production: вручную перепроверить уменьшение отдельных знаков до 16/24/32 px, при необходимости отдельно оптимизировать favicon; проверить правовую уникальность/товарный знак. Эти задачи не блокируют разработку структуры сайта.

## Принятие решения

Дизайнер в чате 2026-11-10 явно выбрал основной логотип с кубом и утвердил резервный логотип с угловатой конструкцией. Ранее подготовленные варианты A/B/C отклонены; не возвращаться к ним без новой просьбы.

# IRONCORE — 3 новых направления логотипа

**Задача:** создать три профессиональные, заметно разные SVG-композиции для обсуждения. Не объявлять победителя, пока дизайнер не подтвердил выбор. По переписке старый логотип сперва принимали, но затем запросили варианты.

## Наследуемые элементы / ожидания заказчика
- Название `IRONCORE` написано именно так, латиница, без ошибок.
- От эскиза клиента: красно-синий контраст, круги вместо букв O или в самостоятельном знаке; допустима геометрическая доработка и новые формы.
- В присланной истории: белые буквы, первая O красная с тёмным центром, вторая O синяя; небольшой знак из перекрывающихся красного и синего кругов.
- Клиент разрешает фантазировать: **не обязательно повторять форму кругов один в один**; пиктограмма может быть другой, важно сохранить качество и релевантность.

## Три исследуемые концепции (не готовые логотипы)
1. **Эволюция «двух ядер»** — чистый компактный wordmark, авторский рисунок O и самостоятельный геометрический знак на основе двух напряжённых круговых форм. Не просто два случайных круга.
2. **Инженерный модуль** — знак через две-три геометрические формы, архитектурное ядро/оболочку/защищённую структуру. Сдержанный, читаемый на 20–24px, без банального щита и галочки.
3. **Монограмма IC / I+C** — собственная буквенная архитектура с негативным пространством; не копировать стандартные IT-монограммы.

## Что разработать для каждой
- Главная горизонтальная композиция (знак + IRONCORE).
- Монохромная версия 1 цвет; версия на тёмном и светлом фоне.
- Отдельный знак 24/32px, favicon 16–32px.
- SVG, без растрового содержимого, без фильтров и сомнительных шрифтовых зависимостей; геометрически согласованные пропорции.
- Показать в реальной шапке сайта при ширине 1440px и на мобильном 390px.
- Краткий разбор — читаемость, оригинальность, связь с инженерной тематикой и риски.

## Отбор
- Отличительный силуэт и запоминаемость важнее декоративности.
- Сохранять профессиональный, строгий характер без клише «кибербезопасность», молний, щитов, замков, серверных иконок.
- Основной выбранный вариант попадёт в `assets/logos/current/`, альтернативы — в `assets/logos/concepts/`; **пока этих файлов нет**.
- Использовать цветовые ориентиры из прошлого эскиза: синий `#1E3A8A`, красный `#D62839`, графит `#141821`; точные цвета ещё могут быть скорректированы.
- Не использовать старый архив `docs/archive/previous-brand.md` как инструкцию «логотип уже утверждён» — это исторический документ.

# IronCore — тема WordPress

- **Готовый архив:** `dist/ironcore-theme.zip` → Внешний вид → Темы → Добавить → Загрузить.
- **Исходники PHP:** `ironcore/`. CSS, JS, шрифты и картинки берутся из корня репозитория при сборке.
- **Пересобрать после правок:** `./wordpress/build-theme.sh` (нужны bash и zip).
- **Полная инструкция для разработчика:** [docs/wordpress-handoff.md](../docs/wordpress-handoff.md).
